# ABX Global — лендинг

Продакшн-вёрстка по ТЗ `ABX-site-brief.md`: 10 секций в порядке клиента, только тёмная тема.

## Стилистика
Последний проход сделан скиллом [unslop](https://github.com/heydamir/unslop) (Damir Sokolovsky, @heydamir, CC BY 4.0) по всем девяти шагам.

**Направление**
- **Продукт:** регулируемый в ЕС брокер. Даёт чешским клиентам торговать акциями, ETF, сырьём, форексом, индексами и pre-IPO с одного счёта.
- **Характер:** точный, ночной, чуть горячий.
- **Мир:** ночная гонка. Мокрый асфальт, карбон, раскалённые тормоза, экраны тайминга.
- **Моменты:** сцена в hero (болид и искры) и терминал со свечами. Весь цвет и вся детализация сосредоточены в них.
- **Подпись:** тег позиции из timing tower с оранжевой чертой: номера секций, P1–P9 в таблице рынков, P1–P4 в шагах.

**Система**
- **Цвета:** «асфальтовая» нейтральная шкала (#111110 / #171716 / #20201E), три роли текста, один акцент #FF711D.
- **Шрифты:** Geist и Geist Mono, веса 400–500, иерархия строится размером и цветом.
- **Сетка и радиусы:** шаг 4px; радиусы 8 / 12 / 20 вложены друг в друга; разделители — линии с прозрачностью 8%.
- **Движение:** одна кривая `cubic-bezier(.22,1,.36,1)`; одно появление при загрузке (hero); hover только меняет цвет и фон; зацикленных анимаций нет.

**Где сознательно разошлись с ТЗ** (по рекомендациям unslop, при желании возвращается):
- Вторая строка заголовков секций теперь вторичного цвета. Оранжевой она осталась только в hero.
- Точки в конце заголовков убраны.
- Счётчики цифр, бегущая строка логотипов и появление блоков при скролле убраны: по unslop это движение без смысла.
- Радиусы 8–20px вместо 5–6px. Кнопки больше не пилюли.
- Стартовые огни в шагах убраны: подпись у продукта должна быть одна.
- Рендеры монеты и бейджа в Security убраны: на секцию один объект, щит.

**Что ещё нужно**
- Hero держится на нарисованной кодом сцене. Для боевой версии нужна настоящая фотография или генерация, промпт в отчёте к сессии.
- С референсов (Revolut, capital.com, Apple) не удалось снять замеры: домены закрыты сетевой политикой.

## Как открыть
```bash
cd abx-site && python3 -m http.server 8123
```
`http://localhost:8123/` открывает чешскую версию (по умолчанию), `/en/` английскую.
`?placeholders` подсвечивает все заглушки на странице.

## Структура
- `content/cs.json`, `content/en.json`: все тексты сайта, ключи у обоих языков совпадают.
- `src/index.html`: шаблон. `{{key}}` подставляет текст, `{{=var}}` подставляет переменную сборки.
- `tools/build.mjs`: собирает `index.html` (cs) и `en/index.html`. Падает, если ключ пропущен или в языках разный набор ключей.
- `assets/css/site.css`, `assets/js/site.js`: стили и поведение без зависимостей (искры в hero, счётчики, аккордеон, Exclusive, график).
- `tools/optimize-media.sh`: делает из оригиналов клиента AVIF/WebP с `srcset` и пережимает видео до размера меньше 3 МБ.
- `PLACEHOLDERS.md`: список того, что ждём от клиента.

После правки текста или шаблона запустить `node tools/build.mjs`.

## Чего не было в исходниках
`v2.html`, картинки, видео, шрифты PP Formula и ссылки на Figma в репозитории нет. Поэтому:
- Визуалы нарисованы кодом: силуэт болида, искры на canvas, 3D-плашки, щит, монета, бейдж, терминал, телефон, руль. В разметке оставлены закомментированные слоты `<picture>` под фото (`hero`, `commodities`, `forex`, `cockpit`). Если раскомментировать слот, фото ляжет поверх рисованной заглушки.
- Шрифт сейчас Geist; PP Formula клиента можно вернуть в заголовки через `--f-display`. PP Formula подключается раскомментированием `@font-face` в начале `site.css` после того, как файлы лягут в `assets/fonts/`. Веб-лицензию нужно проверить.
- Визуально с `v2.html` и фреймом Figma ещё не сверено: это следующий шаг, когда будут исходники.

## Проверено
- 375, 768, 1440, 1920: горизонтального скролла нет.
- Lighthouse (mobile): Performance 97, Accessibility 100, Best Practices 100.
- Вкладки таблицы рынков, аккордеон и Exclusive: aria-expanded, `inert` на закрытых панелях, раскрытие через анимацию высоты (`grid-template-rows`).
- `prefers-reduced-motion`: анимаций нет, всё видно сразу, вместо анимированных искр статичный кадр.
- Для SEO при выкладке `hreflang` нужно поменять на абсолютные URL (Lighthouse SEO 90 из-за этого).
